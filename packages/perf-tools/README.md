# perf-tools (Rust)

Perf-critical primitives: ripgrep-backed file search, sandbox helpers (seccomp/bwrap on Linux, sandbox-exec on macOS), hash/diff utilities.

Shipped as optional per-platform native modules. TS core calls via stdio JSON-RPC, no FFI.
